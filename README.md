## 🎯 About

**Tarot League** is a competitive online platform for French Tarot — a strategic 4-player trick-taking card game with a 78-card deck, hugely popular in France and now accessible worldwide.

🔗 **Official website**: [https://tarot-league.com](https://tarot-league.com)

## ✨ Features

- 🏆 **Ranked mode** — RP system, ranks Bronze → Master, quarterly seasons
- 🤖 **Solo mode** — Play against 3 smart AIs (3 difficulty levels)
- 👥 **Real-time multiplayer** — 4 player tables with matchmaking
- 🌍 **Worldwide leaderboard** — Compete with players globally
- 📊 **Detailed statistics** — Per-contract stats, win streaks, match history
- 🔐 **Easy login** — Google Sign-In or email
- 🔄 **Auto-reconnect** — Resume after network drops
- 💎 **100% free** — No ads, no in-app purchases

## 🃏 What is French Tarot?

French Tarot is a strategic trick-taking card game played with a 78-card Tarot Nouveau deck. It combines:

- **Bidding phase** — Players bid (Petite, Garde, Garde Sans, Garde Contre) to become the *Taker*
- **Card play** — Taker plays alone against the 3 *Defenders*
- **Announcements** — Optional bonuses: Poignée (Handful), Chelem (Grand Slam), Pas de prise (No-bid)
- **Scoring** — Based on captured points + Trumps (Atouts), Kings, Queens, Knights, Knaves, plus the "oudlers" (1, 21, Excuse)

Tarot League implements the **official FFT (Fédération Française de Tarot)** rules.

## 🛠️ Tech Stack

- **[Godot Engine 4.4](https://godotengine.org)** — Open-source game engine for cross-platform clients
- **[Nakama 3.21](https://heroiclabs.com/nakama)** — Real-time multiplayer backend with PostgreSQL storage
- **PostgreSQL 15** — Persistent player data, leaderboards, season archives
- **Cloudflare Pages** — Marketing site hosting
- **Resend** — Transactional emails (verification, password reset)

## 🚀 Quick start

### Play in browser
Just go to [tarot-league.com](https://tarot-league.com) — no install required.

### Windows
1. Download `TarotLeague-setup.exe` from [tarot-league.com](https://tarot-league.com#download)
2. Run the installer
3. Launch from Start menu

### Android (alpha)
The Android version is currently in **closed alpha testing**. To request testing access, contact us via the website.
